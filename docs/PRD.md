# PRD: 유튜브 썸네일 생성기

## 목표
유튜버가 프롬프트만으로 클릭을 부르는 16:9 썸네일을 1분 안에 만들도록 한다.

## 사용자
영상은 만들지만 디자인 툴(포토샵 등)은 서툰 1인 유튜버. 영상 업로드 직전, 머릿속 아이디어(프롬프트)·가끔 본인 얼굴/제품 사진·박고 싶은 문구를 들고 온다.

## 핵심 기능
1. 프롬프트(필수) + 참고 이미지(옵션) + 썸네일 문구(옵션) 입력
2. `gpt-image-2`로 16:9 썸네일 후보 여러 장(2~4) 동시 생성
3. 마음에 드는 후보를 PNG로 다운로드

## MVP 제외 사항
- 로그인 / 결제
- DB / 이미지 영구 저장 / 생성 히스토리
- 이미지 후처리(크롭·필터·텍스트 편집)

## 디자인
- 다크모드 고정, 미니멀, 단일 페이지
- 무채색 + 포인트 1색

## 유저 저니 (요약)
상태머신 `idle → loading → success | error`. 검증 실패는 `idle`에 머물며 인라인 처리.
- **idle**: 폼(프롬프트 필수 / 문구 옵션 / 참고 이미지 옵션 / 후보 수 2·3·4, 기본 2 / 생성 버튼).
- **제출 전 검증**: 프롬프트 공백 → 버튼 비활성 + 인라인 안내. 이미지 형식(PNG/JPG/WebP)·크기(≤10MB) 위반 → 인라인 안내.
- **loading**: 스피너 + "생성 중… (최대 1분 소요)", 폼 비활성(중복 제출 방지).
- **success**: 결과 N장 그리드 + 각 카드 다운로드(`thumbnail-{idx}.png`) + [다시 생성]. 입력값 유지.
- **error**: 폼 상단 배너 + 입력 유지. 재시도 가능한 오류만 [재시도] 노출.

## 에러 처리 (요약, 4버킷)
사용자 행동이 갈리는 단위로만 구분한다.
| 코드 / HTTP | 발생 | 문구 | 재시도 |
|---|---|---|---|
| `INVALID_INPUT` / 400 | 프롬프트 공백·이미지 형식/크기 위반 | "프롬프트를 입력해주세요" / "PNG·JPG·WebP, 10MB 이하만 가능해요" | 인라인 |
| `MISSING_API_KEY` / 503 | 서버에 API 키 없음 | "서버에 API 키가 설정되지 않았습니다" | ✕ |
| `CONTENT_POLICY` / 422 | 콘텐츠 정책 거부 | "콘텐츠 정책에 의해 거부됐어요. 프롬프트를 수정해주세요" | ✕ |
| `GENERATION_FAILED` / 502 | 그 외 전부(레이트리밋·타임아웃·네트워크·미상) | "이미지 생성에 실패했어요. 잠시 후 다시 시도해주세요" | ✓ |
